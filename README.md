# Lamplight — The Second Reading

The published daily reading. **This repository contains one built HTML page and
nothing else** — the source, pipeline and passage index live in a private repository.

`.gitignore` denies everything by default and allows only `index.html`, `.nojekyll`
and this file.

Scripture is the Berean Standard Bible, public domain. News is headlines and links
only, each attributed to and linking back to the publisher that reported it.
